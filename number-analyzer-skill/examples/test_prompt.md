# Number Analyzer Skill 测试 Prompt

请使用 `number-analyzer` Skill 分析以下数字，并且必须调用 Python 工具函数 `analyze_numbers()` 完成计算。

输入数字：

12, 15, 14, 10, 18, 100, 16, 13, 15, 17

执行要求：
1. 将数字按原始顺序传入工具。
2. 计算基础统计指标、总体和样本离散程度。
3. 计算 Q1、Q2、Q3 和 IQR。
4. 使用 IQR 方法检测潜在异常值。
5. 统计正数、负数、零、整数的数量。
6. 找出重复值及其出现次数。
7. 最终只输出合法 JSON，不要使用 Markdown 代码块，不要添加任何额外解释。
8. 所有统计结果必须来自工具实际返回值，不要在 Agent 侧自行估算。
